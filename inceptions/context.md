# AI Coder Project Context: PSHS-MC Forms and Manuals Web Application

## Project Overview

This project is a web application that serves as a centralized, easily accessible repository for forms and manuals from the Philippine Science High School - Main Campus (PSHS-MC). It automates the process of downloading these documents from the official website and presents them in a clean, searchable web interface. The application is deployed as a static website on GitHub Pages.

## Core Components

### Python Scripts

-   `download_forms.py`: This script is responsible for downloading the forms. It contains a hardcoded list of URLs (`form_urls`). When executed, it fetches each file and saves it to the `forms/` directory. It also generates `downloaded_files.json`, which is a list of the successfully downloaded files.
-   `manual_download.py`: This script is similar to `download_forms.py` but is intended for downloading manuals.
-   `generate_index.py`: This script generates the main `index.html` file. It reads the list of files from the `forms/` directory, creates a title for each, and injects the list as a JavaScript array into the `index.html` template.
-   `create_manual_index.py` & `generate_manuals_page.py`: These scripts work together to create the `manuals.html` page, which is dedicated to listing the manuals.

### HTML Files

-   `index.html`: The main landing page of the application. It displays a searchable list of all the forms. The data for the forms is populated by `generate_index.py`.
-   `manuals.html`: A dedicated page for manuals, generated by `generate_manuals_page.py`.
-   `webpage.html` & `webpage_content.html`: These seem to be templates or parts of the web interface.

### Directories

-   `forms/`: This directory stores all the downloaded forms.
-   `manuals/`: This directory contains the downloaded manuals, organized by category.
-   `.github/workflows/`: Contains the GitHub Actions workflow for CI/CD.

### CI/CD

-   `.github/workflows/static.yml`: This file defines a GitHub Actions workflow that automatically deploys the entire repository to GitHub Pages on every push to the `main` branch. This means any changes to the HTML, CSS, JS, or the downloaded files will be live once merged.

## Workflow

1.  **Downloading Forms & Manuals**:
    -   The URLs of the forms and manuals are manually added to the `form_urls` list in `download_forms.py` and `manual_download.py`.
    -   Running `python3 download_forms.py` downloads the forms into the `forms/` directory.
    -   Running `python3 manual_download.py` downloads the manuals into the `manuals/` directory.

2.  **Generating the Web Interface**:
    -   Running `python3 generate_index.py` reads the contents of the `forms/` directory and injects the file list into `index.html`.
    -   Running `python3 generate_manuals_page.py` does the same for the manuals and populates `manuals.html`.

3.  **Deployment**:
    -   When changes are pushed to the `main` branch on GitHub, the `static.yml` workflow is triggered.
    -   The workflow deploys the entire repository as a static site to GitHub Pages.

This setup creates a self-contained system for maintaining an up-to-date repository of important school documents.
