## SIDE A: Step-by-Step Guides

### How to Record a Disease Case

**1. Open the Disease Tracker**
- Go to Google Drive
- Open `Infectious_Disease_Monitoring_2026`

**2. Add a New Case**
- Enter Date Reported in column A
- Enter Student/Employee Name in column B
- Select Disease Type from dropdown in column C (Flu, Dengue, Chickenpox, etc.)
- Enter Symptoms in column E
- Enter Date Onset in column F
- Select Status from dropdown in column G (Active, Recovered, Referred)
- Enter Notes in column I

**3. Update Case Status**
- When student recovers, enter Date Cleared in column H
- Change Status to "Recovered"
- Row color changes from red to green automatically

**4. Monitor Active Cases**
- Look for rows with red background (Active cases)
- Follow up on these cases daily
- Update status as needed

---

### How to Create a Disease Chart

**1. Select Your Data**
- Open the disease tracker spreadsheet
- Select the data range including headers and all cases

**2. Insert Chart**
- Click **Insert** → **Chart**
- Choose chart type (Column chart recommended)
- Google Sheets will suggest a chart based on your data

**3. Customize the Chart**
- Add chart title: "Disease Cases by Type - 2026"
- Add axis labels if needed
- Choose colors that match PSHS branding
- Click **Insert**

**4. Update Chart**
- Chart updates automatically when you add new data
- To edit, click the chart and click the three dots → **Edit chart**
- Change chart type, colors, or data range as needed

---

### How to Create Health Campaign Slides

**1. Open Google Slides**
- Go to `slides.google.com`
- Click **+ Blank** to create a new presentation

**2. Create Title Slide**
- Click in title box: Enter campaign name (e.g., "Dengue Prevention Campaign")
- Click in subtitle: Add a brief description
- Add background color or image

**3. Create Content Slides**
- Click **Insert** → **Slide** (or `Ctrl+M`)
- Add title and content for each slide
- Use bullet points for readability
- Keep text concise and scannable

**4. Add Visual Elements**
- Click **Insert** → **Image** → Upload relevant images
- Add shapes or icons for emphasis
- Use consistent colors and fonts throughout
- Add PSHS logo to each slide

**5. Export as PDF**
- Click **File** → **Download** → **PDF Document (.pdf)**
- Print as posters or share digitally

---

### How to Create a Health Survey

**1. Create the Form**
- Go to `forms.google.com`
- Click **+ Blank**
- Name the survey (e.g., "Dengue Awareness Survey")

**2. Add Demographic Questions**
- Grade Level (Dropdown: Grade 7-12)
- Section/Class (Short answer)

**3. Add Knowledge Questions**
- How is the disease transmitted? (Multiple choice)
- What are the symptoms? (Checkboxes)
- How can we prevent it? (Checkboxes)

**4. Add Behavior Questions**
- How often do you practice prevention? (Dropdown)
- Do you use protective measures? (Yes/No)

**5. Add Feedback Questions**
- What other topics should we address? (Paragraph)
- How can we improve campaigns? (Paragraph)

**6. Configure and Share**
- Click **Settings** → Enable "Collect email addresses" (optional)
- Click **Responses** → Link to a Google Sheet
- Click **Send** → Copy the link
- Share with students

**7. Analyze Responses**
- Open the response spreadsheet
- Use charts to visualize results
- Identify knowledge gaps
- Use data to improve future campaigns

### Common Mistakes to Avoid

| Mistake | Why It's a Problem | Fix |
|---------|-------------------|-----|
| Not updating case status | Tracker doesn't reflect current situation | Update status immediately when student recovers |
| Using inconsistent disease names | Data analysis becomes difficult | Use dropdown with standard disease names |
| Not protecting student privacy | Data security risk | Share only with authorized HSU staff |
| Not backing up data | Risk of data loss | Download as .ods regularly (LibreOffice backup) |
| Forgetting to update bulletin board | Information becomes outdated | Schedule regular updates (weekly or as needed) |
| Not analyzing survey data | Missed opportunities for improvement | Use charts to identify gaps in knowledge |
| Using complex formulas incorrectly | Data errors | Test formulas with sample data first |
| Not following DOH Calendar | Missed health observances | Check DOH calendar when planning campaigns |

### Emergency: What to Do If...

| Situation | Solution |
|-----------|----------|
| Disease outbreak occurs | Immediately update tracker, notify SSD Chief, create advisory |
| Chart not showing new data | Refresh chart or check data range |
| Can't find a specific case | Use Ctrl+F to search by name or ID |
| Survey link not working | Check sharing permissions, regenerate link |
| Need to print campaign materials | Export Slides as PDF, print as posters |
| Internet is down | Use LibreOffice to work offline, upload when online |
| Data accidentally deleted | Use version history to restore (File → Version history) |
| Need to create urgent advisory | Create a new Slide, export as PDF, share via email |
| Multiple staff need access | Share folder with appropriate permissions (Viewer/Editor) |
| Need to analyze survey data | Use pivot tables and charts to visualize results |

### Remember the Analogies

**Physical Bulletin Board → Google Slides**

| Physical Bulletin Board | Google Slides |
|----------------------|--------------|
| Post paper posters | Digital slides |
| Hard to update | Update instantly |
| One location | Accessible from anywhere |
| Can't track views | Can track views and engagement |
| Limited space | Unlimited slides |
| Paper waste | Digital, eco-friendly |
| Hard to archive | Automatically saved |

**Paper Logbook → Google Sheet**

| Paper Logbook | Google Sheet |
|---------------|--------------|
| Write by hand | Type on keyboard |
| One person at a time | Multiple people simultaneously |
| Can be lost/damaged | Backed up automatically |
| Hard to search | Search in seconds |
| Manual calculations | Automatic formulas |
| Paper pages | Infinite rows |

### Tips for Success

1. **Update tracker daily** during disease outbreaks
2. **Use consistent naming** for all files and folders
3. **Create reusable slide templates** for different health topics
4. **Analyze survey data** to improve future campaigns
5. **Follow DOH Calendar** when planning campaigns (per SSM 6.5)
6. **Back up data weekly** by downloading as .ods (LibreOffice)
7. **Protect student privacy** — share only with authorized staff
8. **Use charts to communicate** trends to stakeholders
9. **Update bulletin board regularly** with current health information
10. **Keep SSM manuals accessible** for reference
