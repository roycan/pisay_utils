## SIDE A: Step-by-Step Guides

### How to Compose and Send an Email

**1. Open Gmail**
- Go to `mail.google.com`
- You should be automatically signed in with your PSHS email

**2. Compose Email**
- Click the **Compose** button (pencil icon)
- **To:** Enter recipient's email address
- **Cc:** Include others who need to see the email
- **Bcc:** Include recipients without others seeing their addresses
- **Subject:** Type a clear, descriptive subject line
- **Body:** Type your message
- **Attachments:** Click the paperclip icon to attach files
- Click **Send**

**3. Check Sent Email**
- Click **Sent** on the left sidebar
- Your sent emails appear here

---

### How to Organize Emails with Labels

**1. Create a Label**
- On the left sidebar, find **Labels**
- Click **+ Create**
- Name your label (e.g., "Urgent", "Training", "Project A")
- Click **Create**

**2. Apply a Label**
- Select the email(s) by clicking the checkbox
- Click the **Label** icon (tag icon)
- Check the box next to the label(s) you want to apply
- Click **Apply**

**3. View Labeled Emails**
- Click the label name on the left sidebar
- All emails with that label appear

---

### How to Create Folders in Google Drive

**1. Open Google Drive**
- Go to `drive.google.com`

**2. Create a Folder**
- Click **+ New** → **Folder**
- Name your folder
- Click **Create**

**3. Create Subfolders**
- Double-click to open your folder
- Click **+ New** → **Folder**
- Name the subfolder
- Click **Create**

**4. Upload Files**
- Open the folder where you want to upload
- Click **+ New** → **File upload**
- Select files from your computer
- Wait for upload to complete

---

### How to Share Files and Folders

**1. Share with Specific People**
- Right-click the file or folder
- Click **Share**
- Enter email addresses
- Choose access level: **Viewer**, **Commenter**, or **Editor**
- Click **Send**

**2. Share with a Link**
- Right-click the file or folder
- Click **Share**
- Click **Change** under "General access"
- Select **Anyone with the link**
- Choose access level
- Click **Copy link**
- Share the link with others

---

### How to Create a Calendar Event

**1. Open Google Calendar**
- Go to `calendar.google.com`

**2. Create Event**
- Click on the date and time
- Enter event title
- Select date and time
- Add description (optional)

**3. Add Guests**
- Click **Add guests**
- Enter email addresses
- Guests receive an invitation

**4. Set Reminders**
- Click **Add notification**
- Choose when to be reminded (e.g., 10 minutes before)
- Click **Save**

**5. Save Event**
- Click **Save**
- Choose to send invitations if prompted

---

### How to Send a Chat Message

**1. Open Google Chat**
- Click the **Chat** icon in Google Workspace
- Or go to `chat.google.com`

**2. Start a Chat**
- Find a colleague's name on the left
- Click on their name
- Type your message
- Press **Enter** to send

**3. Create a Group Chat**
- Click **+ Start a chat**
- Enter names of multiple people
- Type your message
- Press **Enter** to send

---

### How to Work Offline with LibreOffice

**1. Download Google Files**
- Open the file in Google Docs, Sheets, or Slides
- Click **File** → **Download**
- Choose format:
  - **.odt** for documents (LibreOffice Writer)
  - **.ods** for spreadsheets (LibreOffice Calc)
  - **.odp** for presentations (LibreOffice Impress)

**2. Open in LibreOffice**
- Double-click the downloaded file
- LibreOffice opens automatically

**3. Work Offline**
- Make your edits
- Save the file

**4. Upload When Online**
- Go to `drive.google.com`
- Drag and drop the file
- Google converts it back to Google format

*Note: LibreOffice will be deployed campus-wide before full training rollout*

### Google Chat vs Gmail: When to Use Which

| Google Chat | Gmail |
|-------------|-------|
| Quick, real-time conversations | Formal, documented communication |
| Like texting or instant messaging | Like sending a memo or letter |
| Use when you need immediate response | Use when you need a record |
| Informal discussions | Official communication |
| Best for: Quick questions, team updates | Best for: Attachments, formal requests, documentation |

### Common Mistakes to Avoid

| Mistake | Why It's a Problem | Fix |
|---------|-------------------|-----|
| Using PSHS email for Netflix/Shopee | Violates FAM 12.2 Section 3.2.4 | Use personal email for personal accounts |
| Forgetting to CC relevant people | Others miss important information | Always think about who needs to see the email |
| Not using labels | Hard to find emails later | Create labels and apply them consistently |
| Sharing with wrong permissions | People can edit when they shouldn't | Check permissions before sharing |
| Not setting calendar reminders | Miss important meetings | Always add reminders to events |
| Using Chat for formal communication | No record of conversation | Use Gmail for official communication |
| Not organizing files in Drive | Hard to find files later | Create folders and use descriptive names |

### Emergency: What to Do If...

| Situation | Solution |
|-----------|----------|
| Can't access Gmail | Check internet connection. Try clearing browser cache. |
| Can't find an email | Use search bar. Check "All Mail" folder. |
| Accidentally deleted email | Check "Trash" folder. Restore if within 30 days. |
| Can't share a file | Verify recipient has PSHS Google account. Check email address. |
| Calendar event disappeared | Check other calendar views. Verify correct date. |
| Chat message not sending | Check internet connection. Verify recipient is online. |
| Internet is down | Use LibreOffice to work offline (once deployed). |
| Forgot password | Contact ISA to reset password. |
| Suspicious email | Don't click links. Report to ITU immediately. |
| Need to access from home | Use `mail.google.com`, `drive.google.com`, etc. from any browser. |

### Tips for Success

1. **Use descriptive names** for folders, files, and labels
2. **Check sharing permissions** before sharing sensitive information
3. **Set calendar reminders** so you never miss important events
4. **Use stars** to mark important emails and files
5. **Organize as you go**—don't let files pile up
6. **Use search** instead of scrolling through hundreds of emails
7. **Keep your inbox clean** by archiving or deleting old emails
8. **Use keyboard shortcuts** to work faster
9. **Back up important files** by downloading them regularly
10. **Follow PSHS email policies** to avoid violations
