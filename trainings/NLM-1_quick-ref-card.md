## SIDE A: Step-by-Step Guides

### How to Record Meeting Audio on Your Phone

**1. Open Your Voice Recorder App**
- Find the voice recorder app on your phone
- Most phones have one built-in (Voice Recorder, Sound Recorder, etc.)

**2. Start Recording**
- Tap the record button (usually a red circle)
- The app will start recording and show a timer

**3. Position Your Phone**
- Place near the center of the table
- Keep upright and stable
- Don't cover the microphone

**4. During the Meeting**
- Speak clearly
- Ask participants to speak one at a time
- Avoid side conversations

**5. Stop and Save**
- Tap the stop button when done
- Name the file clearly (e.g., "Staff_Meeting_2025-04-17.mp3")
- Save the file

**6. Transfer to Computer**
- Email the file to yourself
- Upload to Google Drive and download
- Use a USB cable to transfer

---

### How to Upload Audio to NotebookLM

**1. Open NotebookLM**
- Go to notebooklm.google.com
- Sign in with your Google account

**2. Create a New Notebook**
- Click "Create" or the "+" button
- Name your notebook (e.g., "Staff Meeting - April 17, 2025")
- Click "Create"

**3. Add Audio Source**
- Click "Add Source"
- Select "Audio" from the options
- Click "Upload" and select your audio file
- Wait for upload and processing to complete

**4. Review Auto-Generated Content**
- Summary appears automatically
- Key Topics are identified
- Audio Overview is available

---

### How to Generate a Meeting Summary

**1. Review the Auto-Generated Summary**
- Look at the "Summary" section in your notebook
- Read through to understand the meeting content

**2. Explore Key Topics**
- Click on "Key Topics"
- Click on individual topics to see relevant excerpts
- Use this to structure your minutes

**3. Generate Audio Overview (Optional)**
- Click "Generate Audio Overview"
- Wait for it to create the audio
- Listen to a 2-3 minute podcast-style summary

**4. View Original Audio**
- Click on the audio source in your notebook
- See the full recording with timestamps
- Jump to specific points in the meeting

### How to Prompt for Action Items and Decisions

**Extract Action Items:**
```
List all action items from this meeting, including:
- What needs to be done
- Who is responsible
- Any deadlines mentioned
```

**Extract Decisions:**
```
List all decisions made during this meeting, including:
- What was decided
- The context or background
- Any conditions or next steps
```

**Summarize by Topic:**
```
Summarize the discussion about [specific topic].
```

**Identify Attendees:**
```
List all participants who spoke during the meeting and summarize their main contributions.
```

**Find Follow-Up Items:**
```
What follow-up actions are needed after this meeting?
```

### How to Format Minutes in Google Docs

**1. Create New Document**
- Go to docs.google.com
- Click "Blank"
- Name your document

**2. Add Meeting Header**
```
[Meeting Title]
Date: [Date]
Time: [Start Time] - [End Time]
Location: [Location]
Chairperson: [Name]
Attendees: [List]
```

**3. Copy Content from NotebookLM**
- Copy the Summary for introduction
- Copy Key Topics for main body
- Copy Action Items and Decisions for conclusions

**4. Format the Document**
- Use headings for each section
- Use bullet points for lists
- Use bold for emphasis
- Add a table for action items

**5. Review and Edit**
- Read through the entire document
- Verify accuracy using citations
- Add any missing information
- Check spelling and grammar

**6. Share and Distribute**
- Share with attendees
- Convert to PDF if needed
- Save to appropriate folder in Google Drive

### Audio Recording Best Practices

**Before Recording:**
- [ ] Test your voice recorder app
- [ ] Ensure sufficient storage space
- [ ] Check battery level or plug in
- [ ] Inform participants that meeting is being recorded

**Positioning:**
- [ ] Place phone near center of table
- [ ] Keep upright and stable
- [ ] Don't cover the microphone
- [ ] Use a stand if available

**Environment:**
- [ ] Choose a quiet room
- [ ] Close doors and windows
- [ ] Turn off noisy fans or AC
- [ ] Avoid rooms with echoes

**During Meeting:**
- [ ] Speak clearly
- [ ] Ask participants to speak one at a time
- [ ] Ask quiet speakers to speak up
- [ ] Avoid side conversations

**Technical:**
- [ ] Use highest quality setting
- [ ] Record in MP3 or WAV format
- [ ] Name file clearly
- [ ] Start recording before meeting begins

### Common Mistakes and Solutions

| Mistake | Solution |
|---------|----------|
| Poor audio quality | Position phone better, choose quieter room |
| Forgot to start recording | Have backup recorder, ask colleague to record |
| Audio file too large | Break into segments, compress if needed |
| NotebookLM gives poor results | Check audio quality, try different prompts |
| Can't find action items | Use specific action items prompt |
| Citations don't work | Refresh page, ensure audio is fully loaded |
| Can't copy to Google Docs | Use keyboard shortcuts (Ctrl+C, Ctrl+V) |
| Minutes too long | Focus on decisions and action items only |
| Missing important information | Use specific prompts to extract it |
| Unclear who is responsible | Ask NotebookLM about responsibilities |

### NotebookLM Limitations

1. **Audio Quality Dependency:** Poor audio = poor results
2. **Context Understanding:** May miss nuances, sarcasm, or implicit understanding
3. **Technical Limits:** File size limits, processing time, occasional errors
4. **Not a Replacement for Human Judgment:** Always review and edit
5. **Language Support:** Best with English and major languages
6. **Real-time Processing:** Not designed for live transcription
7. **Speaker Identification:** May not distinguish between similar voices

### Emergency Solutions

**Audio Won't Upload:**
- Try a different browser
- Convert to MP3 format
- Compress the file
- Contact ITU for help

**NotebookLM Down:**
- Use Google Docs transcription as backup
- Manually transcribe key points
- Try again later

**Meeting in Progress, Recording Failed:**
- Take detailed notes manually
- Ask colleagues for their notes
- Request a brief recap at end of meeting
- Reschedule if critical information was missed

**Need Minutes Immediately:**
- Focus on decisions and action items only
- Skip detailed discussion summaries
- Issue draft minutes, update later
- Ask chairperson for priority items
