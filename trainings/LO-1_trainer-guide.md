## Learning Objectives

By the end of this session, participants will be able to:

1. Understand what LibreOffice is and why it's needed as an offline backup
2. Install LibreOffice (or verify it's already installed)
3. Use LibreOffice Writer to create, open, and save documents (.odt, .docx)
4. Use LibreOffice Calc to create, open, and save spreadsheets (.ods, .xlsx)
5. Use LibreOffice Impress to create, open, and save presentations (.odp, .pptx)
6. Download Google Workspace files in LibreOffice formats for offline use
7. Work offline in LibreOffice and upload files back to Google Drive when online
8. Set up Google Drive desktop app for offline file access (optional)

## In-Person Session Script

### 1. Welcome and Quick Q&A (5 minutes)

**Trainer Script:**

"Good morning/afternoon, everyone! Welcome to LO-1: LibreOffice as Offline Backup.

This session is about ensuring business continuity. What happens when the internet goes down? What if Google Workspace is temporarily unavailable? That's where LibreOffice comes in—it's your offline backup.

Before we dive in, let's address any questions you might have from the pre-session video. Who has questions about LibreOffice, file formats, or the offline workflow?"

**Anticipated Questions & Answers:**

| Question | Answer |
|----------|--------|
| "Why do we need LibreOffice if we have Google Workspace?" | Google Workspace requires internet. When internet is down or Google is unavailable, you still need to work. LibreOffice lets you work offline and upload later. It's your backup plan. |
| "Is LibreOffice free?" | Yes! LibreOffice is completely free and open-source. No license fees, no subscriptions. PSHS can deploy it campus-wide at no cost. |
| "Can I open Microsoft Office files in LibreOffice?" | Yes! LibreOffice can open .docx, .xlsx, and .pptx files. It can also save in these formats if needed. |
| "Will my Google files work in LibreOffice?" | Yes! You can download Google Docs as .odt, Google Sheets as .ods, and Google Slides as .odp. LibreOffice opens these natively. |
| "Do I need to learn a completely new software?" | No! LibreOffice is very similar to Microsoft Office. If you've used Word, Excel, or PowerPoint, you'll feel right at home. |

**Trainer Script:**

"Great questions! Remember, LibreOffice is your safety net. It ensures you can keep working even when internet is unavailable. Let's move to our first topic: Introduction to LibreOffice."

### 2. Introduction to LibreOffice (5 minutes)

**Trainer Script:**

"Let's start with the basics. What is LibreOffice?

LibreOffice is a free, open-source office suite. It includes:
- **Writer:** For documents (like Microsoft Word or Google Docs)
- **Calc:** For spreadsheets (like Microsoft Excel or Google Sheets)
- **Impress:** For presentations (like Microsoft PowerPoint or Google Slides)

**Why do we need it at PSHS?**

1. **Offline Backup:** When internet is down, you can still work
2. **Cost-Effective:** It's free—no licensing costs
3. **Compatibility:** Works with Microsoft Office and Google Workspace formats
4. **Campus-Wide Deployment:** Will be installed on all PSHS computers before full training rollout

**Key File Formats:**

| Application | LibreOffice Format | Microsoft Format | Google Format |
|-------------|-------------------|------------------|---------------|
| Writer | .odt | .docx | Google Docs |
| Calc | .ods | .xlsx | Google Sheets |
| Impress | .odp | .pptx | Google Slides |

**Trainer Script:**

"LibreOffice uses open formats (.odt, .ods, .odp) by default. These are standardized formats that any software can open. But LibreOffice can also work with Microsoft formats (.docx, .xlsx, .pptx) if needed."

### 3. LibreOffice Writer (Documents) (12 minutes)

**Trainer Script:**

"Now let's look at LibreOffice Writer. This is for creating documents—reports, letters, memos, and more."

#### Step-by-Step Demo Script

**Step 1: Open LibreOffice Writer**

1. Click the **Start** menu (Windows) or **Applications** (Mac/Linux)
2. Find and click **LibreOffice**
3. Click **Writer Document** (or the Writer icon)
4. A blank document opens

**Step 2: Create a Simple Document**

[SCREEN: Typing in LibreOffice Writer]

**Trainer Script:**

"Let's create a simple memo. Type the following:

```
MEMORANDUM

To: All Staff
From: [Your Name]
Date: April 16, 2026
Subject: LibreOffice Training

This is a sample memo created in LibreOffice Writer.

LibreOffice allows us to work offline when internet is unavailable.
```

**Step 3: Format the Document**

1. Select "MEMORANDUM" and make it **Bold** and **Centered**
2. Select the To/From/Date/Subject lines and make them **Bold**
3. Increase the font size of "MEMORANDUM" to 16 or 18
4. Adjust spacing as needed

**Step 4: Save the Document**

1. Click **File** → **Save As**
2. Name the file: `Sample_Memo.odt`
3. Choose a location (e.g., Documents or Desktop)
4. Click **Save**

**Trainer Script:**

"Notice the file extension is .odt—this is LibreOffice's native format. But you can also save as .docx if you need to share with Microsoft Office users."

**Step 5: Save in Microsoft Format (Optional)**

1. Click **File** → **Save As**
2. In the "Save as type" dropdown, select **Microsoft Word 2007-365 (.docx)**
3. Name the file: `Sample_Memo.docx`
4. Click **Save**

**Step 6: Open a Google Doc in LibreOffice**

[SCREEN: Downloading from Google Docs]

**Trainer Script:**

"Now let's see how to open a Google Doc in LibreOffice.

1. Open Google Drive in your browser
2. Open any Google Doc
3. Click **File** → **Download** → **OpenDocument Text (.odt)**
4. The file downloads to your computer
5. Double-click the downloaded .odt file
6. LibreOffice Writer opens automatically

You can now edit the document offline!"

**Step 7: Upload Back to Google Drive**

1. Save your changes in LibreOffice
2. Open Google Drive in your browser
3. Click **+ New** → **File upload**
4. Select the edited .odt file
5. Google converts it back to Google Docs format
6. The file appears in your Google Drive

### 6. Offline Workflow (8 minutes)

**Trainer Script:**

"Now let's put it all together. Here's the complete offline workflow:

**Scenario: Internet is down, but you need to work on a report.**

**Step 1: Prepare in Advance (When Internet is Available)**
1. Download important Google Docs as .odt files
2. Download important Google Sheets as .ods files
3. Download important Google Slides as .odp files
4. Save them to your computer or a USB drive

**Step 2: Work Offline (When Internet is Down)**
1. Open LibreOffice
2. Open the .odt, .ods, or .odp file you need
3. Make your edits
4. Save your changes

**Step 3: Upload When Online (When Internet Returns)**
1. Open Google Drive in your browser
2. Click **+ New** → **File upload**
3. Select the edited file
4. Google converts it back to Google format
5. The file appears in your Google Drive

**Trainer Script:**

"This workflow ensures you never lose productivity due to internet outages. Work offline, upload when online—simple as that!"

**Optional: Google Drive Desktop App**

[SCREEN: Google Drive desktop app interface]

**Trainer Script:**

"For even better offline access, you can install the Google Drive desktop app. This creates a Google Drive folder on your computer that syncs automatically.

1. Go to `drive.google.com`
2. Click the Settings gear → **Get Drive for desktop**
3. Download and install the app
4. Sign in with your PSHS Google account
5. A Google Drive folder appears on your computer
6. Files you save here sync automatically when online

This is optional but highly recommended for frequent offline work."

## Troubleshooting Tips

### Common Mistakes and Solutions

| Mistake | Solution |
|---------|----------|
| Can't find LibreOffice | Check that it's installed. Look in Start menu or Applications. If not installed, contact ITU. |
| File won't open | Verify the file format. LibreOffice opens .odt, .ods, .odp natively. For .docx/.xlsx/.pptx, ensure you have the latest LibreOffice version. |
| Formula not working in Calc | Check that you used the correct syntax. Formulas start with `=`. Use semicolons `;` instead of commas `,` in some regions. |
| Can't upload to Google Drive | Check internet connection. Verify file size (Google Drive has limits). Try a different browser. |
| Formatting looks different after upload | Some formatting may not transfer perfectly. Minor adjustments may be needed in Google Workspace. |
| Can't save file | Check that you have write permissions to the location. Try saving to a different folder (e.g., Desktop or Documents). |
| LibreOffice crashes | Restart LibreOffice. If the problem persists, contact ITU. |

### Tips for Success

1. **Save frequently** — Ctrl+S to save your work
2. **Use keyboard shortcuts** — They're the same as in Microsoft Office
3. **Prepare in advance** — Download files you might need before internet goes down
4. **Keep backups** — Save important files to multiple locations
5. **Learn the basics** — Focus on Writer, Calc, and Impress—these cover 90% of use cases
6. **Use native formats** — .odt, .ods, .odp work best in LibreOffice
7. **Upload promptly** — When internet returns, upload your files immediately
8. **Install Google Drive desktop app** — For automatic syncing (optional but recommended)

## Trainer Notes

- **Pace:** Adjust timing based on participant comfort level. If participants are struggling with a particular application, spend more time on it.
- **Analogies:** Emphasize the Swiss Army knife analogy—LibreOffice is one tool that handles multiple formats.
- **Real Examples:** Use actual PSHS scenarios to make the training more relevant.
- **Focus on Basics:** Don't get bogged down in advanced features. Focus on creating, opening, saving, and uploading.
- **Reassure Participants:** Many may be nervous about learning "new" software. Emphasize that LibreOffice is very similar to Microsoft Office.
- **Follow-up:** Schedule a check-in with unit heads 1 month after training to address any issues.
