## SIDE A: Step-by-Step Guides

### How to Book a Facility

**1. Open the Facility Calendar**
- Go to `calendar.google.com`
- Select `Facility Booking - PSHS-MC` from the left sidebar

**2. Check Availability**
- Navigate to the desired date
- Check if the facility is already booked
- Look for available time slots

**3. Create a Booking Event**
- Click on the desired date and time
- Event title: `[Facility Name] - [Purpose]`
- Example: `Science Lab 1 - Grade 7 Class`

**4. Add Event Details**
- Description: Include requestor name, purpose, number of participants, equipment needed
- Example:
  ```
  Requestor: Juan dela Cruz
  Purpose: Laboratory Activity
  Participants: 30 students
  Equipment: Microscopes, beakers, safety goggles
  ```

**5. Add Guests (Optional)**
- Enter email addresses of relevant staff
- They will receive notification of the booking

**6. Save the Event**
- Click **Save**
- The booking appears on the shared calendar for everyone to see

**7. Update if Needed**
- To modify: Click the event → Click the pencil icon → Make changes → Save
- To cancel: Click the event → Click the trash icon → Confirm

---

### How to Book a Vehicle

**1. Open the Vehicle Calendar**
- Go to `calendar.google.com`
- Select `Vehicle Booking - PSHS-MC` from the left sidebar

**2. Check Availability**
- Navigate to the desired date and time
- Check if the vehicle is already booked

**3. Create a Booking Event**
- Click on the desired date and time
- Event title: `[Vehicle Type] - [Destination]`
- Example: `School Van - National Museum`

**4. Add Event Details**
- Description: Include requestor, destination, purpose, passengers, driver
- Example:
  ```
  Requestor: Maria Santos
  Destination: National Museum, Manila
  Purpose: Educational Tour
  Passengers: 15 students, 2 teachers
  Driver: Pedro Reyes
  ```

**5. Save the Event**
- Click **Save**
- The booking appears on the shared calendar

**6. Record Trip Details**
- After the trip, update the event with:
  - Actual departure time
  - Actual return time
  - Odometer reading
  - Fuel consumption

### How to Submit a Facility Permit

**1. Open the Permit Form**
- Go to the Facility Permit Form link
- Form: `Permit to Use School Facilities`

**2. Fill in Requestor Information**
- Name of Requestor
- Department/Unit
- Email Address
- Contact Number

**3. Fill in Facility Details**
- Facility to be Used (dropdown)
- Date of Use
- Time Start and Time End
- Purpose of Use

**4. Select Equipment Needed**
- Check all equipment required
- If "Other" is selected, specify

**5. Review and Submit**
- Review all information
- Click **Submit**
- You will receive a confirmation email

**6. Track Approval Status**
- GSU staff will review the request
- Check the response spreadsheet for status updates
- You will be notified of approval or disapproval

### How to Conduct a Performance Evaluation

**1. Open the Evaluation Spreadsheet**
- Go to Google Drive
- Open `Janitorial_Performance_Evaluation_2026` or `Security_Guard_Performance_Evaluation_2026`

**2. Enter Employee Information**
- Employee Name
- Date of Evaluation
- Evaluator Name

**3. Score Each Criterion**
- Enter scores for each criterion (based on point values)
- Example criteria for janitorial staff:
  - Attendance (5 points)
  - Punctuality (5 points)
  - Quality of Work (20 points)
  - Completeness of Tasks (15 points)
  - Compliance with Schedule (15 points)
  - Attitude/Cooperation (15 points)
  - Safety Practices (10 points)
  - Equipment Care (5 points)

**4. View Automatic Calculations**
- Total Score calculates automatically (SUM formula)
- Rating assigns automatically (IF formula):
  - 90-100: Outstanding
  - 80-89: Very Satisfactory
  - 70-79: Satisfactory
  - 60-69: Fair
  - Below 60: Poor

**5. Add Comments**
- Enter any comments or feedback in the Comments column
- Note areas for improvement or commendations

**6. Save the Evaluation**
- The spreadsheet saves automatically
- Share with the employee and relevant supervisors

---

### How to Complete a Cleaning Checklist

**1. Open the Checklist Form**
- Go to the Cleaning Checklist Form link
- Form: `Cleaning_Checklist`

**2. Fill in Area Information**
- Area Being Cleaned (dropdown)
- Date of Cleaning
- Janitor Name

**3. Complete Cleaning Tasks**
- For each task, select **Completed** or **Not Completed**
- Tasks include:
  - Floor swept and mopped
  - Surfaces dusted and wiped
  - Trash bins emptied
  - Restrooms sanitized
  - Windows cleaned
  - Mirrors polished

**4. Record Supplies Used**
- Check all supplies used
- If "Other" is selected, specify

**5. Complete Overall Assessment**
- Select Overall Cleanliness (Excellent, Good, Fair, Poor)
- Add any comments or issues

**6. Submit the Checklist**
- Click **Submit**
- Data is recorded in the response spreadsheet

### Common Mistakes to Avoid

| Mistake | Why It's a Problem | Fix |
|---------|-------------------|-----|
| Not checking calendar before booking | Causes double-bookings | Always check availability first |
| Forgetting to add event details | Confusion about booking purpose | Always include requestor, purpose, participants |
| Not updating calendar for cancellations | Facility appears booked when available | Cancel or update events promptly |
| Using incorrect formula syntax | Calculations don't work | Verify formula syntax, check parentheses |
| Not sharing calendar with all staff | Some can't see bookings | Share with all authorized staff |
| Forgetting to submit permit | Request not processed | Always click Submit after filling form |
| Not completing all checklist items | Incomplete cleaning records | Complete all items before submitting |
| Not backing up data | Risk of data loss | Download as .ods regularly (LibreOffice backup) |

### Emergency: What to Do If...

| Situation | Solution |
|-----------|----------|
| Facility double-booked | Contact both parties, reschedule one, update calendar |
| Vehicle breaks down during trip | Contact GSU immediately, arrange alternative transport |
| Permit form not accessible | Check sharing permissions, contact GSU |
| Evaluation formula not working | Check formula syntax, verify referenced cells contain numbers |
| Checklist responses not appearing | Check that form is linked to spreadsheet |
| Need to print permit | Open response spreadsheet, print relevant row |
| Internet is down | Use LibreOffice to work offline, upload when online |
| Data accidentally deleted | Use version history to restore (File → Version history) |
| Need urgent approval | Contact GSU directly by phone or in person |
| Multiple staff need access | Share folder with appropriate permissions (Viewer/Editor) |
| Calendar not syncing | Refresh page, check internet connection, sign out and sign back in |

### Remember the Analogies

**Wall Calendar → Google Calendar**

| Wall Calendar | Google Calendar |
|--------------|----------------|

| Hard to check availability | Instant availability check |

### Tips for Success

1. **Check calendar first** before making any bookings
2. **Add detailed descriptions** to all calendar events
3. **Update calendars promptly** for any changes or cancellations
4. **Use consistent naming** for all events and files
5. **Submit permits early** (at least 2 days before per FAM 6.2)
6. **Complete evaluations regularly** (semi-annual per FAM 6.3 and 6.6)
7. **Back up data weekly** by downloading as .ods (LibreOffice)
8. **Protect sensitive data** — share only with authorized staff
9. **Use formulas** to automate calculations and reduce errors
10. **Follow FAM procedures** for all permits and evaluations
