## SIDE A: Step-by-Step Guides

### How to Create a Document in LibreOffice Writer

**1. Open LibreOffice Writer**
- Click **Start** → **LibreOffice** → **Writer Document**
- A blank document opens

**2. Create Your Document**
- Type your content
- Use toolbar to format (Bold, Italic, Underline, etc.)
- Insert images, tables, or other elements as needed

**3. Save Your Document**
- Click **File** → **Save As**
- Name your file
- File extension is `.odt` (LibreOffice format)
- Click **Save**

**4. Save in Microsoft Format (Optional)**
- Click **File** → **Save As**
- In "Save as type," choose **Microsoft Word 2007-365 (.docx)**
- Click **Save**

---

### How to Create a Spreadsheet in LibreOffice Calc

**1. Open LibreOffice Calc**
- Click **Start** → **LibreOffice** → **Spreadsheet**
- A blank spreadsheet opens

**2. Enter Data**
- Click a cell and type
- Use arrow keys to move between cells
- Press Enter to confirm entry

**3. Use Formulas**
- Start with `=` (equals sign)
- Examples:
  - `=SUM(A1:A10)` — Add values in range
  - `=A1*B1` — Multiply two cells
  - `=AVERAGE(A1:A10)` — Calculate average
- Press Enter to see result

**4. Save Your Spreadsheet**
- Click **File** → **Save As**
- Name your file
- File extension is `.ods` (LibreOffice format)
- Click **Save**

**5. Save in Microsoft Format (Optional)**
- Click **File** → **Save As**
- In "Save as type," choose **Microsoft Excel 2007-365 (.xlsx)**
- Click **Save**

---

### How to Create a Presentation in LibreOffice Impress

**1. Open LibreOffice Impress**
- Click **Start** → **LibreOffice** → **Presentation**
- Click **Create** for blank presentation

**2. Create Slides**
- Click in title box to add title
- Click in content box to add text or images
- Click **Insert** → **Slide** to add new slide (or `Ctrl+M`)

**3. Format Slides**
- Use toolbar to change fonts, colors, sizes
- Add images: **Insert** → **Image**
- Add shapes: **Insert** → **Shape**

**4. Save Your Presentation**
- Click **File** → **Save As**
- Name your file
- File extension is `.odp` (LibreOffice format)
- Click **Save**

**5. Save in Microsoft Format (Optional)**
- Click **File** → **Save As**
- In "Save as type," choose **Microsoft PowerPoint 2007-365 (.pptx)**
- Click **Save**

---

### How to Open Google Files in LibreOffice

**For Google Docs:**
1. Open Google Drive
2. Open the Google Doc
3. Click **File** → **Download** → **OpenDocument Text (.odt)**
4. File downloads to your computer
5. Double-click the `.odt` file
6. LibreOffice Writer opens automatically

**For Google Sheets:**
1. Open Google Drive
2. Open the Google Sheet
3. Click **File** → **Download** → **OpenDocument Spreadsheet (.ods)**
4. File downloads to your computer
5. Double-click the `.ods` file
6. LibreOffice Calc opens automatically

**For Google Slides:**
1. Open Google Drive
2. Open the Google Slide presentation
3. Click **File** → **Download** → **OpenDocument Presentation (.odp)**
4. File downloads to your computer
5. Double-click the `.odp` file
6. LibreOffice Impress opens automatically

---

### How to Upload Files Back to Google Drive

**1. Open Google Drive**
- Go to `drive.google.com`

**2. Upload File**
- Click **+ New** → **File upload**
- Select your LibreOffice file (.odt, .ods, or .odp)
- Click **Open**

**3. Wait for Conversion**
- Google automatically converts the file
- File appears in Google Drive in Google format

**4. Verify Conversion**
- Open the file to check formatting
- Make minor adjustments if needed

---

### Complete Offline Workflow

**When Internet is Available:**
1. Download important Google Docs as `.odt`
2. Download important Google Sheets as `.ods`
3. Download important Google Slides as `.odp`
4. Save files to your computer or USB drive

**When Internet is Down:**
1. Open LibreOffice
2. Open the file you need to work on
3. Make your edits
4. Save your changes (`Ctrl+S`)

**When Internet Returns:**
1. Open Google Drive
2. Upload your edited file
3. Google converts it back to Google format
4. File appears in your Google Drive

### File Format Quick Reference

| Application | LibreOffice Format | Microsoft Format | Google Format |
|-------------|-------------------|------------------|---------------|
| Documents | `.odt` | `.docx` | Google Docs |
| Spreadsheets | `.ods` | `.xlsx` | Google Sheets |
| Presentations | `.odp` | `.pptx` | Google Slides |

**Tip:** Use LibreOffice formats (.odt, .ods, .odp) for best compatibility within LibreOffice. Use Microsoft formats (.docx, .xlsx, .pptx) when sharing with Microsoft Office users.

### Common Formulas for LibreOffice Calc

| Formula | Description | Example |
|---------|-------------|---------|
| `=SUM(range)` | Add values in range | `=SUM(A1:A10)` |
| `=AVERAGE(range)` | Calculate average | `=AVERAGE(B1:B10)` |
| `=COUNT(range)` | Count cells with numbers | `=COUNT(C1:C10)` |
| `=MAX(range)` | Find maximum value | `=MAX(D1:D10)` |
| `=MIN(range)` | Find minimum value | `=MIN(E1:E10)` |
| `=A1*B1` | Multiply two cells | `=A2*B2` |
| `=A1/B1` | Divide two cells | `=A3/B3` |
| `=TODAY()` | Insert today's date | `=TODAY()` |
| `=NOW()` | Insert current date and time | `=NOW()` |

**Note:** In some regions, use semicolons `;` instead of commas `,` in formulas.

### Common Mistakes to Avoid

| Mistake | Why It's a Problem | Fix |
|---------|-------------------|-----|
| Not saving frequently | Risk of losing work | Press `Ctrl+S` often |
| Using wrong file format | Compatibility issues | Use .odt/.ods/.odp for LibreOffice |
| Forgetting to upload | Work not synced to cloud | Upload when internet returns |
| Not checking conversion | Formatting may be lost | Verify after upload |
| Using complex formatting | May not convert well | Keep formatting simple |
| Not backing up files | Risk of data loss | Save to multiple locations |

### Emergency: What to Do If...

| Situation | Solution |
|-----------|----------|
| Can't find LibreOffice | Check Start menu. If not installed, contact ITU. |
| File won't open | Verify file format. LibreOffice opens .odt, .ods, .odp natively. |
| Formula shows error | Check syntax. Use `=` at start. Use semicolons if commas don't work. |
| Can't save file | Check write permissions. Try saving to Desktop or Documents. |
| Upload failed | Check internet connection. Verify file size. Try different browser. |
| Formatting looks wrong | Some formatting may not convert. Make minor adjustments in Google. |
| LibreOffice crashes | Restart LibreOffice. If problem persists, contact ITU. |
| Need to share with Microsoft user | Save as .docx/.xlsx/.pptx before sharing. |
| Internet is down | Work offline in LibreOffice. Upload when internet returns. |
| Forgot to download files | Wait for internet to return, then download. |

### Tips for Success

1. **Save frequently** — Press `Ctrl+S` often to avoid losing work
2. **Use native formats** — .odt, .ods, .odp work best in LibreOffice
3. **Prepare in advance** — Download files before internet goes down
4. **Keep backups** — Save important files to multiple locations
5. **Learn keyboard shortcuts** — They speed up your work significantly
6. **Keep formatting simple** — Complex formatting may not convert perfectly
7. **Upload promptly** — When internet returns, upload files immediately
8. **Verify conversions** — Check files after uploading to Google Drive
9. **Install Google Drive desktop app** — For automatic syncing (optional)
10. **Practice regularly** — The more you use LibreOffice, the more comfortable you'll be
