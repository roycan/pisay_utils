## Keywords and Concepts (2 minutes)

[SCREEN: Bulleted list of keywords appears one by one as narrator speaks]

**Narrator:**

"Before we dive in, let's cover some key terms you'll need to know.

**First: Pivot Tables.** A pivot table is a powerful tool in Google Sheets that summarizes and analyzes data. Instead of manually counting cases by disease type, a pivot table does it automatically. You can quickly see which diseases are most common, how many cases are active, and identify trends.

**Second: Charts.** Charts visualize your data in a visual format. A column chart can show the number of cases by disease type. A line chart can show disease trends over time. Visuals make it easier to communicate findings to stakeholders.

**Third: Conditional Formatting.** This automatically changes cell colors based on rules. We'll use it to highlight active disease cases in red so they stand out for immediate attention.

**Fourth: Data Validation.** This ensures data is entered correctly. For disease type, we'll create a dropdown list of options per SSM 6.7. This prevents typos and ensures consistent data entry.

**Fifth: Survey Design.** Good surveys ask clear, unbiased questions that gather useful data. We'll use Google Forms to create health awareness surveys that help us measure the effectiveness of our campaigns."

## Pattern Demonstration (8-10 minutes)

### Disease Monitoring Tracker (3 minutes)

[SCREEN: Screen recording of creating a Google Sheet]

**Narrator:**

"Let's start with the disease monitoring tracker. Go to drive.google.com, click New, and select Google Sheets. Name it 'Infectious_Disease_Monitoring_2026.'

Set up column headers: Date Reported, Student/Employee Name, Grade Level, Disease Type, Symptoms, Date Onset, Status, Date Cleared, Days Absent, and Notes.

[SCREEN: Adding data validation and conditional formatting]

**Narrator:**

"Add data validation for Disease Type. Select the column, go to Data, Data validation, and choose Dropdown. Add the diseases per SSM 6.7: Acute Viral/Bacterial Conjunctivitis, Viral Exanthems, Parotitis, Dengue Infections, Amoebiasis, Typhoid Fever, Hepatitis A, and Other.

Add data validation for Status with options: Active, Recovered, Referred, and Under Observation.

Now let's add conditional formatting. Select all columns, go to Format, Conditional formatting. Add a rule: if Status equals 'Active,' show red background. This makes active cases immediately visible.

Add a formula in the Days Absent column to automatically calculate the number of days between onset and clearance.

[SCREEN: Creating a pivot table and chart]

**Narrator:**

"To analyze the data, let's create a pivot table. Select all your data, click Insert, Pivot table. In the pivot table editor, add Disease Type as rows and Status as columns. This shows a summary of cases by disease type and status.

Now let's create a chart. Select the pivot table data, click Insert, Chart. Choose a column chart. This visualizes the data and makes it easy to present to stakeholders."

### Health Campaign Materials (3 minutes)

[SCREEN: Screen recording of creating Google Slides]

**Narrator:**

"Now let's create health campaign materials in Google Slides. Go to drive.google.com, click New, and select Google Slides. Name it 'Dengue_Prevention_Campaign_2026.'

Create a title slide with the campaign name and a subtitle explaining the purpose.

Create a second slide explaining what the disease is, its symptoms, and prevention methods. Use bullet points for clarity.

Create a third slide with actionable steps students can take—the 4-S campaign for dengue: Search and Destroy, Self-Protection Measures, Seek Early Consultation, and Support Fogging/Spraying.

Create a final slide with a call to action—what students can do to help prevent the disease.

Add images, icons, and consistent colors to make the slides visually appealing. When done, export as PDF for printing or digital distribution."

### Health Awareness Surveys (2 minutes)

[SCREEN: Screen recording of creating a Google Form]

**Narrator:**

"Finally, let's create a health awareness survey to assess the effectiveness of our campaigns. Go to forms.google.com and click Blank. Name it 'Dengue_Awareness_Survey_2026.'

Add demographic questions: Grade Level and Section.

Add knowledge assessment questions: How is dengue transmitted? What are the symptoms? How can we prevent it? Use multiple choice and checkboxes for easy analysis.

Add behavior assessment questions: How often do you check for stagnant water? Do you use mosquito repellent?

Add feedback questions: What other health topics should we address? How can we improve our campaigns?

Link the form to a Google Sheet to collect all responses. Use the data to identify knowledge gaps and improve future campaigns."

## Production Notes for Video Recording

### Technical Requirements
- **Resolution:** 1920x1080 (1080p) minimum
- **Audio:** Clear narration, no background noise
- **Screen Recording:** Use zoom-in features for small text and buttons
- **Pacing:** Speak clearly and at a moderate pace; allow pauses for viewers to process information

### Visual Style
- **Color Scheme:** Use PSHS branding colors where appropriate
- **Font:** Clean, readable sans-serif (Arial, Roboto, or similar)
- **Transitions:** Simple cuts or fades; avoid flashy transitions
- **Annotations:** Use arrows, circles, or highlights to draw attention to specific elements

### Accessibility
- **Captions:** Include closed captions for accessibility
- **Visual Cues:** Use visual indicators to reinforce concepts
- **Pacing:** Allow time for viewers to read on-screen text before moving on

### Distribution
- **Format:** MP4 or WebM
- **File Size:** Compress to under 500MB for easy sharing via email or Google Drive
- **Hosting:** Upload to Google Drive and share link 2-3 days before the in-person session
- **Deadline:** Ensure video is available to participants at least 48 hours before the session

---

## Important Notes for the Trainer

1. **Emphasize SSM Compliance:** Throughout the video, reference SSM 6.7 and 6.5 to show how digital tools comply with manual requirements.

2. **Use HSU-Specific Examples:** When demonstrating, use actual HSU scenarios (e.g., dengue outbreaks, flu season, vaccination campaigns).

3. **Highlight Data Privacy:** Emphasize the importance of protecting student health data. Share spreadsheets only with authorized staff.

4. **Focus on Practical Tools:** Concentrate on tools HSU will use daily—tracker, charts, campaigns, surveys.

5. **Mention DOH Calendar:** Reference the Department of Health calendar when planning health campaigns (per SSM 6.5).
