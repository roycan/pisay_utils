# LO-1 Hands-On Exercise: LibreOffice as Offline Backup

**Duration:** 7 minutes
**Format:** Guided step-by-step exercise
**Prerequisites:** Watched pre-session video, Session 0 completed

---

## Exercise Scenario

You are a PSHS-MC staff member preparing for potential internet outages. Your task is to practice using LibreOffice to create documents, spreadsheets, and presentations, then upload them to Google Drive.

---

## Step-by-Step Instructions

### Part 1: LibreOffice Writer (Documents) (2 minutes)

#### Task 1: Create a Simple Memo

1. Click the **Start** menu (Windows) or **Applications** (Mac/Linux)
2. Find and click **LibreOffice**
3. Click **Writer Document** (or the Writer icon)
4. A blank document opens

5. Type the following memo:

```
MEMORANDUM

To: Unit Head
From: [Your Name]
Date: April 16, 2026
Subject: LO-1 Practice Exercise

This is a practice document created in LibreOffice Writer as part of the
Google Workspace training. I am learning to use LibreOffice as an offline
backup solution.

Key benefits of LibreOffice:
- Free and open-source
- Works offline
- Compatible with Google Workspace
- Compatible with Microsoft Office
```

6. Format the document:
   - Select "MEMORANDUM" and make it **Bold**, **Centered**, and increase font size to 18
   - Select the To/From/Date/Subject lines and make them **Bold**
   - Select the "Key benefits" line and make it **Bold**
   - Select the bullet points and make them a bulleted list (if not already)

7. Save the document:
   - Click **File** → **Save As**
   - Name the file: `LO1_Practice_Memo.odt`
   - Choose a location (e.g., Documents or Desktop)
   - Click **Save**

**Expected Outcome:** You have a formatted memo saved as `LO1_Practice_Memo.odt`.

### Part 2: LibreOffice Calc (Spreadsheets) (2 minutes)

#### Task 2: Create a Simple Inventory Tracker

1. In LibreOffice, click **File** → **New** → **Spreadsheet**
2. A blank spreadsheet opens

3. Create headers:
   - Cell **A1**: Type `Item`
   - Cell **B1**: Type `Quantity`
   - Cell **C1**: Type `Unit Cost`
   - Cell **D1**: Type `Total Cost`

4. Format the header row:
   - Select row 1 (click the 1 on the left)
   - Make it **Bold**
   - Add a background color (light gray or light blue)

5. Enter sample data:
   - Cell **A2**: `Ballpoint Pens`
   - Cell **B2**: `50`
   - Cell **C2**: `15`

   - Cell **A3**: `Bond Paper (Ream)`
   - Cell **B3**: `10`
   - Cell **C3**: `250`

   - Cell **A4**: `Stapler`
   - Cell **B4**: `5`
   - Cell **C4**: `120`

6. Calculate total costs:
   - Cell **D2**: Type `=B2*C2` and press Enter
   - Cell **D3**: Type `=B3*C3` and press Enter
   - Cell **D4**: Type `=B4*C4` and press Enter

7. Calculate grand total:
   - Cell **A5**: Type `GRAND TOTAL`
   - Make it **Bold**
   - Cell **D5**: Type `=SUM(D2:D4)` and press Enter
   - Make it **Bold**

8. Save the spreadsheet:
   - Click **File** → **Save As**
   - Name the file: `LO1_Inventory.ods`
   - Choose a location
   - Click **Save**

**Expected Outcome:** You have a working inventory tracker with calculations, saved as `LO1_Inventory.ods`.

### Part 3: LibreOffice Impress (Presentations) (2 minutes)

#### Task 3: Create a Simple Presentation

1. In LibreOffice, click **File** → **New** → **Presentation**
2. A presentation wizard opens—click **Create** to start with a blank presentation

3. Create Slide 1 (Title Slide):
   - Click in the title box and type: `LibreOffice Training`
   - Click in the subtitle box and type: `Offline Backup Solution for PSHS-MC`

4. Create Slide 2:
   - Click **Insert** → **Slide** (or press `Ctrl+M`)
   - Click in the title box and type: `Why LibreOffice?`
   - Click in the content box and type:
     ```
     • Free and open-source software
     • Works offline when internet is unavailable
     • Compatible with Microsoft Office formats
     • Compatible with Google Workspace formats
     • Will be deployed campus-wide
     ```

5. Create Slide 3:
   - Click **Insert** → **Slide**
   - Click in the title box and type: `My Unit`
   - Click in the content box and type: `[Your Unit Name]`
   - Add a bullet point: `We use LibreOffice for offline backup`

6. Save the presentation:
   - Click **File** → **Save As**
   - Name the file: `LO1_Presentation.odp`
   - Choose a location
   - Click **Save**

**Expected Outcome:** You have a 3-slide presentation saved as `LO1_Presentation.odp`.

[SCREENSHOT: LibreOffice Impress with 3-slide presentation]

### Part 4: Upload to Google Drive (1 minute)

#### Task 4: Upload All Files to Google Drive

1. Open your web browser and go to `drive.google.com`
2. Click **+ New** → **File upload**
3. Navigate to where you saved your LibreOffice files
4. Select all three files:
   - `LO1_Practice_Memo.odt`
   - `LO1_Inventory.ods`
   - `LO1_Presentation.odp`
5. Click **Open**
6. Wait for the upload to complete
7. Verify that all three files appear in your Google Drive

**Expected Outcome:** All three LibreOffice files are uploaded to Google Drive and converted to Google Workspace format.

## Troubleshooting

If you encounter issues, check these common problems:

| Problem | Solution |
|---------|----------|
| Can't find LibreOffice | Check that it's installed. Look in Start menu or Applications. If not installed, contact ITU. |
| Formula shows #VALUE! error | Check that you're using numbers, not text. Verify cell references are correct. |
| Can't save file | Check that you have write permissions to the location. Try saving to Desktop or Documents. |
| File won't open | Verify the file format. LibreOffice opens .odt, .ods, .odp natively. |
| Upload to Google Drive failed | Check internet connection. Verify file size. Try a different browser. |
| Formatting looks different after upload | Some formatting may not transfer perfectly. Minor adjustments may be needed. |
| Can't find uploaded file | Check your Google Drive. It may be in a different folder or recently uploaded. |

## Offline Workflow Reminder

Remember the complete offline workflow:

**When Internet is Available:**
1. Download important Google Docs as .odt
2. Download important Google Sheets as .ods
3. Download important Google Slides as .odp
4. Save to your computer

**When Internet is Down:**
1. Open LibreOffice
2. Open the file you need
3. Make your edits
4. Save your changes

**When Internet Returns:**
1. Open Google Drive
2. Upload your edited file
3. Google converts it back
4. File appears in your Drive
