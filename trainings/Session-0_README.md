# Session-0 Training Materials

## Overview

This folder contains all training materials for **Session-0: Google Workspace Fundamentals**, the foundational session for all PSHS-MC administrative units. This session is mandatory for all staff and provides the baseline knowledge required for all subsequent unit-specific training sessions.

## Session Information

| Field | Value |
|-------|-------|
| **Session ID** | Session-0 |
| **Session Title** | Google Workspace Fundamentals |
| **Duration** | 1 hour 30 minutes (90 minutes) |
| **Prerequisites** | Basic computer literacy (can use a mouse, keyboard, and web browser) |
| **Google Workspace Tools** | Gmail, Drive, Calendar, Docs, Sheets, Slides, Forms, Meet, Chat |
| **Manual Reference** | FAM 12.2 Information Technology Management V2_Rev3 |
| **Target Audience** | All PSHS-MC staff (mandatory for all units) |

## Teaching Methodology

### Flipped Classroom Approach

**Part 1: Pre-Session Video (10-15 min, asynchronous)**
- Participants watch the video 2-3 days before the in-person session
- Covers analogy, keywords, patterns, and examples
- Includes screen recordings of actual Google Workspace tools
- Ends with a quick check question

**Part 2: In-Person Session (90 min, synchronous, hands-on)**
- Welcome and Q&A on video (5 min)
- Gmail Essentials & PSHS Email Policies (15 min)
- Google Drive: Files, Folders, Sharing (20 min)
- Google Calendar Basics (10 min)
- Google Chat vs Gmail (5 min)
- LibreOffice Overview (5 min)
- Audience Practice: Guided exercises (20 min)
- Contest Activity: Independent challenge (10 min)
- Wrap-up & Scoring (5 min)

### Gamification: Inter-Unit Competition

- Each unit earns points based on participant performance
- Scoring criteria: Completion (40 pts), Accuracy (40 pts), Independence (20 pts)
- Visible leaderboard tracks unit progress across all sessions
- Points accumulate across the entire training program

## Key Learning Outcomes

By the end of Session-0, participants will be able to:

1. Navigate the Google Workspace ecosystem and understand the purpose of each tool
2. Comply with PSHS email policies per FAM 12.2 Section 3.2
3. Use Gmail essentials: composing, replying, CC/BCC, attachments, labels, search
4. Organize files in Google Drive with proper folder structure and sharing permissions
5. Create and manage Google Calendar events with attendees and reminders
6. Distinguish when to use Google Chat vs Gmail for communication
7. Understand LibreOffice as an offline backup alternative
8. Apply basic keyboard shortcuts and tips for efficiency
