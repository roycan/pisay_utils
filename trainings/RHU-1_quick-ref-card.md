## SIDE A: Step-by-Step Guides

### How to Create a Residence Hall Application Form

**1. Create the Form**
- Go to `forms.google.com`
- Click **+ Blank**
- Name the form: `Residence Hall Application Form - SY 2026-2027`

**2. Add Student Information Section**
- Full Name (Short answer)
- Student ID (Short answer)
- Grade Level (Dropdown: Grade 7-12)
- Scholarship Category (Dropdown: Full, Partial, Non-Scholar)
- Gender (Dropdown: Male, Female)

**3. Add Contact Information Section**
- Home Address (Paragraph)
- Distance from Campus (Dropdown: <5km, 5-10km, 10-20km, >20km)
- Parent/Guardian Name (Short answer)
- Parent/Guardian Contact (Short answer)
- Parent/Guardian Email (Short answer)

**4. Add Health Information Section**
- Medical conditions? (Yes/No)
- If yes, describe (Paragraph - conditional)
- Emergency Contact Name (Short answer)
- Emergency Contact Relationship (Short answer)
- Emergency Contact Number (Short answer)

**5. Add Agreement Section**
- I understand accommodation is subject to availability (Required checkbox)
- I agree to comply with all Residence Hall rules (Required checkbox)

**6. Configure and Share**
- Click **Settings** → Enable "Collect email addresses"
- Click **Responses** → Link to a Google Sheet
- Click **Send** → Copy the link
- Share with Registrar for distribution

### How to Use the Resident Management Tracker

**1. Open the Tracker**
- Go to Google Drive
- Open `RHU_Resident_Tracker_2026-2027`

**2. Add a New Resident**
- Enter Student Name in column A
- Enter Student ID in column B
- Enter Grade Level in column C
- Enter Gender in column D
- Enter Room Assignment in column E
- Enter Bed Number in column F
- Select Contract Status from dropdown in column G (Pending, Signed, Active, Terminated)
- Enter Contract Date in column H
- Check Appliances Declared in column I
- Enter fee payment status in columns J and K
- Enter contact information in columns L and M
- Add notes in column N

**3. Update Contract Status**
- Select the Contract Status cell
- Choose from dropdown: Pending → Signed → Active → Terminated
- Row color changes automatically (yellow for Pending, green for Active, red for Terminated)

**4. View Summary Statistics**
- Scroll to the bottom of the sheet
- View total residents, active contracts, pending contracts
- These update automatically as you add or update residents

---

### How to Conduct Room Inspections

**1. Open the Checklist Form**
- Go to `forms.google.com`
- Open `Good_Housekeeping_Checklist`

**2. Perform Inspection**
- Enter Room Number
- Go through each checklist item:
  - Cleanliness: Floor, Bed, Windows, Trash
  - Safety: Door locks, Electrical outlets, Prohibited items, Fire extinguisher
- Mark each as **Passed** or **Needs Improvement**

**3. Complete Assessment**
- Select Overall Condition (Excellent, Good, Fair, Poor)
- Add comments/recommendations
- Indicate if follow-up is required
- If yes, specify follow-up action

**4. Submit**
- Click **Submit**
- Data automatically goes to response spreadsheet

**5. Review Responses**
- Open the response spreadsheet
- Check for "Needs Improvement" items (highlighted in red)
- Schedule follow-up for rooms needing attention

---

### How to Track Leave Passes

**1. Record Leave Pass**
- Open `Leave_Pass_Tracker_2026-2027`
- Enter Student Name, Student ID, Grade Level
- Enter Date of Leave and Time Out
- Enter Destination and Purpose
- Confirm Parent/Guardian Notified
- Enter Approved By
- Leave Status column shows "On Leave" (yellow)

**2. Record Return**
- When student returns, enter Date of Return and Time In
- Duration calculates automatically
- Status changes to "Returned" (green)

**3. Monitor Overdue Returns**
- Look for rows with "On Leave" status
- Check if duration exceeds expected time
- Follow up with student or parent if needed

**4. View Statistics**
- Use filters to show only "On Leave" students
- Count students currently on leave
- Review leave patterns and trends

---

### How to Generate a Contract

**1. Open the Contract Template**
- Go to Google Drive
- Open `Residence_Hall_Contract_Template`

**2. Fill in Student Details**
- Replace [STUDENT_NAME] with actual name
- Replace [STUDENT_ID] with actual ID
- Replace [GRADE_LEVEL] with actual grade
- Replace [AMOUNT] with actual fee amount

**3. Review and Print**
- Review all details for accuracy
- Click **File** → **Print**
- Print two copies (one for student, one for RHU file)

**4. Collect Signatures**
- Student signs both copies
- RHU Head signs both copies
- Give one copy to student, file the other

### Common Tasks Quick Reference

### Common Mistakes to Avoid

| Mistake | Why It's a Problem | Fix |
|---------|-------------------|-----|
| Not linking form to spreadsheet | Responses won't be collected | Always link form to a Google Sheet |
| Forgetting to update contract status | Tracker won't reflect current status | Update status immediately after signing/terminating |
| Not logging return times | Can't track if student returned on time | Always log return time when student returns |
| Incomplete checklist data | Can't identify rooms needing follow-up | Complete all checklist items during inspection |
| Using paper forms only | Data not digitized, hard to track | Enter paper form data into digital system |
| Not backing up data | Risk of data loss | Download as .ods regularly (LibreOffice backup) |
| Sharing with wrong permissions | Data security risk | Use Viewer access for most, Editor only for RHU staff |

### Emergency: What to Do If...

| Situation | Solution |
|-----------|----------|
| Form not receiving responses | Check that form is shared and "Link to Sheets" is configured |
| Can't find a student's record | Use Ctrl+F to search by name or ID in all spreadsheets |
| Student hasn't returned from leave | Check leave tracker, call parent/guardian, follow up |
| Room inspection failed | Re-inspect room, update checklist, schedule follow-up |
| Contract template missing | Check Google Drive, restore from version history if deleted |
| Internet is down | Use LibreOffice to work offline, upload when online |
| Data accidentally deleted | Use version history to restore (File → Version history) |
| Need to print contract | Open template, fill in details, File → Print |
| Parent wants to submit paper form | Accept paper form, enter data into digital system |
| Multiple staff need access | Share folder with appropriate permissions (Viewer/Editor) |

### Remember the Analogies

**Physical Logbook → Google Sheet**

| Physical Logbook | Google Sheet |
|------------------|--------------|
| Write by hand | Type on keyboard |
| One person at a time | Multiple people simultaneously |
| Can be lost/damaged | Backed up automatically |
| Hard to search | Search in seconds |
| Manual status tracking | Automatic color coding |
| Paper pages | Infinite rows |

**Paper Form → Google Form**

| Paper Form | Google Form |
|-------------|-------------|
| Fill out by hand | Submit online |
| Manual data entry | Automatic data collection |
| Hard to track responses | All responses in one spreadsheet |
| Can be lost | Backed up automatically |
| One copy per student | Unlimited submissions |

### Tips for Success

1. **Use consistent naming** for all files and folders
2. **Set up templates** before the school year starts
3. **Train students** on how to use digital forms
4. **Update tracker daily** during enrollment period
5. **Conduct inspections regularly** using the digital checklist
6. **Monitor leave passes** daily, follow up on overdue returns
7. **Back up data weekly** by downloading as .ods (LibreOffice)
8. **Keep SSM manuals accessible** for reference
9. **Share only what's needed** — use appropriate permissions
10. **Print contracts for signatures** until digital signatures are adopted
